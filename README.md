# Ali.dev — پورتفولیوی علی منصوریار

وب‌سایت نمونه‌کار فارسی، راست‌چین و واکنش‌گرا با HTML، CSS و JavaScript.

## انتشار
این مخزن برای GitHub Pages آماده شده است. انتشار به‌صورت خودکار از طریق GitHub Actions انجام می‌شود.

## شخصی‌سازی
- اطلاعات و پروژه‌ها: `index.html`
- ظاهر و رنگ‌ها: `style.css`
- منوی موبایل و تعاملات: `script.js`

فونت Vazirmatn از Google Fonts بارگذاری می‌شود.
